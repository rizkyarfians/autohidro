# Auto Hidro

Company profile Auto Hidro dengan enam bagian utama: identitas, visi dan misi, tantangan budidaya, produk dan layanan, target pasar, serta model bisnis.

## Pratinjau lokal

Jalankan `python3 -m http.server 8000 --directory dist` dari root repo, lalu buka [http://localhost:8000](http://localhost:8000).

Situs ini menggunakan HTML, CSS, dan JavaScript tanpa proses build. Direktori `dist/` dapat dipublikasikan langsung melalui hosting statis. Logo dan foto berasal dari katalog Auto Hidro.
